# Security Policy

## 🔒 Supported Versions

We provide security updates and patches for the following versions of EvoCore:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

---

## 🛡️ Reporting a Vulnerability

Security and isolation are central to EvoCore's design as an immutable scientific appliance. If you discover a security vulnerability (such as a container escape, arbitrary code execution outside the VM, or tampering with cryptographic attestation signatures):

1. **Do NOT report security vulnerabilities via public GitHub issues.**
2. Send an email with a detailed description and proof-of-concept to the maintainers at **security@bio-colab.org** (or open a private security advisory on GitHub).
3. We will acknowledge receipt of your vulnerability report within 48 hours and work with you on a coordinated disclosure timeline.
